# Project-Proposal
This is a project proposal that was made to solve a real-world problem that I wanted to solve. This aims to help users save time trying to find the best websites for their learning.
## What it does
It gives users a short list of links for good websites and the specific part of that website where they will find what they want to learn about
## How it works
It will ask the user to input their grade, age, or self-assessed skill level, or may ask a few questions to help you determine your skill level, it will ask the specific subject (e.g. Math, English.), and the specific topic.
It will then match and filter out the appropriate websites for your learning based on the information it gets from the user.
Finally, it will give the user the link/s for the websites that best suit your topic.
## Example
"I'm in 8th grade, learning about fractions."

Output:

"Here are 3 good websites for 8th-grade fraction lessons: [Site 1], [Site 2], [Site 3]"
"After this, you'll move on to: decimals → percentages → ratios"
